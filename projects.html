VM Migration

Linode Linux Admin Postfix, MySQL, Zabbix, Apache

Project Overview

This involved migrating a number of virtual machines from Linode onto our VM Ware Hypervisor hosted in our own datacentre.

Architecture & Implementation

We had a Zabbix monitoring server, a custom SFTP server which our clients connected to, and another server which HR used for managing employee details.

  • Step 1: Analysed each server, in terms of current specs, software installed, firewall configuration and required user access.
  • Step 2: Documented current configuration for each server
  • Step 3: Created new instances on VMWare with relevant specs for each machine that was to be migrated, installed OS and matching applications
  • Step 4: Backed up application configuration files, databases, user accounts and transferred them to local storage
  • Step 5: Imported backup data onto the VMWare instances for each new virtual machine, setup application configuration, user access and firewall accee
  • Step 6: Notified relevant parties for cut off date when the old Linode instances will be switched off, and the new VMWare will be switched on.
  • Step 7: Monitor the new VMWare instances for any issues and resolve where necessary
  • Step 8: Updated documentation for each server that was migrated

Results

All VMWare instances were running successfully thereafter. The Linode service was then cancelled resulting in a cost saving
