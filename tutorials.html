Setting up Fail2Ban

Fail2Ban Linux Admin SSH

Overview

The below process details how to install Fail2Ban onto Debian 12 or Ubuntu

Details

1. Initial installation: sudo apt install fail2ban 2. For the defaul setup of Fail2Ban on Linux, create a jail.local file: sudo cp /etc/fail2ban/jail.conf /etc/fail2ban/jail.local In the jail.local file, uncomment and change these parameters where necessary: banaction = ufw (This defines that the ban must be implemented by the UFW firewall automatically) banaction_allports = ufw (This defines that the ban must be implemented by the UFW firewall automatically) destemail = it@companyname.com (Change this to the email address to which the Fail2Ban notice should be sent to) ignoreip = 127.0.0.1/8 bantime = 720m (This defines how long an attacker remains blocked. In this case, it is 12 hours) findtime = 10m (This defines the time window in which failures are counted. In this case, it is 10 minutes) maxretry = 3 (This defines the number of failures allowed before a ban of the offending IP is implemented. Now add the the blocking of brute-force SSH attempts. In the jail.local file look for the section for sshd. Adjust the section as below: port = ssh enabled = true logpath = /var/log/fail2ban.log backed = %(sshd_backend)s After making the changes as above, save the file and exit it. Then test the configuration file without starting the service. This will tell you if there are any issues in the configuration file: sudo fail2ban-client -t To start the Fail2Ban service: sudo systemctl start fail2ban To enable the Fail2Ban service upon start-up: sudo systemctl enable fail2ban To check the Fail2Ban service status: sudo systemctl status fail2ban To check the logs for any failed logins in Debian 12: sudo journalct _COMM=sshd To check the logs for any failed logins in Ubuntu 22: sudo tail -f /var/log/auth.log To check if the banned IP addresses have been added to the UFW firewall: sudo ufw status numbered
