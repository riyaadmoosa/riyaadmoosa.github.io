Setting up Fail2Ban

Fail2Ban Linux Admin SSH

Overview

The below process details how to install Fail2Ban onto Debian 12 or Ubuntu It also integrates Fail2Ban with UFW, in that UFW will automatically block the offending IP

Fail2Ban Installation and Configuration

1. Initial Installation

Install Fail2Ban using the following command: 

sudo apt install fail2ban

2. Create the jail.local Configuration

For the default setup of Fail2Ban on Linux, create a jail.local file by copying the default configuration: 

sudo cp /etc/fail2ban/jail.conf /etc/fail2ban/jail.local

Open the jail.local file and uncomment or change the following parameters where necessary.

3. Configure Fail2Ban

banaction = ufw
    banaction_allports = ufw
    destemail = it@companyname.com
    ignoreip = 127.0.0.1/8

    bantime = 720m
    findtime = 10m
    maxretry = 3
  • banaction: Defines that the ban should be implemented automatically using the UFW firewall.
  • banaction_allports: Defines that the offending IP should be blocked across all ports using the UFW firewall.
  • destemail: Change this to the email address to which Fail2Ban notifications should be sent.
  • ignoreip: Specifies IP addresses that should be ignored by Fail2Ban. The default value shown above represents localhost addresses.
  • bantime: Defines how long an offending IP address remains blocked. 720m represents 12 hours.
  • findtime: Defines the time window in which failed attempts are counted. In this configuration, the window is 10 minutes.
  • maxretry: Defines the number of failures allowed before a ban of the offending IP address is implemented. In this configuration, the limit is 3 attempts.

4. Configure SSH Brute-Force Protection

To enable protection against brute-force SSH attempts, locate the [sshd] section in the jail.local file and adjust it as follows: 

[sshd]
port = ssh
enabled = true
logpath = /var/log/fail2ban.log
backend = %(sshd_backend)s

After making the changes, save the file and exit the editor.

5. Test the Configuration

Before starting the Fail2Ban service, test the configuration file. This will identify any configuration errors: 

sudo fail2ban-client -t

6. Start the Fail2Ban Service

Start the Fail2Ban service: 

sudo systemctl start fail2ban

Enable Fail2Ban to start automatically when the system boots: 

sudo systemctl enable fail2ban

7. Check the Service Status

Check the current status of the Fail2Ban service: 

sudo systemctl status fail2ban

8. Check SSH Login Attempts

On Debian 12, SSH authentication events can be viewed using: 

sudo journalctl _COMM=sshd

On Ubuntu 22.04, authentication logs can be monitored using: 

sudo tail -f /var/log/auth.log

9. Check Banned IP Addresses

To check whether banned IP addresses have been added to the UFW firewall: 

sudo ufw status numbered
